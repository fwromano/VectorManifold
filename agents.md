# Codex Agent Notes

## Operating Preferences
- When running experiments or analyses, always deliver a comprehensive report that includes methodology, key results, diagrams/plots, representative sample data, and a clear explanation of what was done and why.
- Favour clear, readable visualisations; provide legends or companion tables when labels must be abbreviated.
- Document assumptions or unresolved questions inline so follow-up work is obvious.

## Reporting Defaults
1. Summarise the goal, data sources, and tooling at the top of each report.
2. Describe the workflow step-by-step (inputs → processing → outputs) before diving into results.
3. Present findings in order of impact, note limitations, and suggest concrete next actions.
4. Attach or reference supporting artefacts (figures, tables, configuration files) so the report is reproducible.

## Repository Hygiene
- Use existing sandbox-friendly commands (`rg`, `python`, etc.) and avoid altering unrelated files.
- Prefer Markdown for human-readable deliverables; keep code cells/scripts under `scripts/` when needed.
